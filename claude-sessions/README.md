# claude-sessions

Lưu bối cảnh giữa các phiên làm việc với Claude (theo quy tắc chung trong `~/.claude/CLAUDE.md`).

| File | Dùng để |
|---|---|
| [TONG-QUAN.md](TONG-QUAN.md) | Tóm tắt dự án: cấu trúc, công nghệ, API, trang quản trị, quy ước |
| [DANG-LAM.md](DANG-LAM.md) | Việc đang dở, việc tiếp theo |
| `YYYY-MM-DD.md` | Nhật ký từng ngày: yêu cầu, đã làm, file đã sửa, quyết định, còn dở |

Mở phiên mới chỉ cần nói "làm tiếp" — Claude tự đọc thư mục này.
